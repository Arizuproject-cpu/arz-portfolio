# ARIZU Portfolio Design System

## Overview

Personal portfolio website for Arizu.

The website should present Arizu as:

* AI Builder
* Automation Engineer
* System Designer
* Orchestration Architect

The goal is to communicate technical capability, systems thinking, and execution quality.

This is NOT:

* a creator portfolio
* a startup landing page
* a SaaS dashboard
* a content showcase

Primary emotion:

"Builder of intelligent systems."

---

# Design Philosophy

Design should feel:

* Professional
* Technical
* Confident
* Clean
* Human

The website should feel like it belongs to someone building AI infrastructure and autonomous systems.

Avoid:

* excessive animations
* flashy effects
* gamer aesthetics
* cyberpunk overload
* social media styling
